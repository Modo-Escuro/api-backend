Carrinho real está aprovado no escopo, mas a nova CART-01 ainda é trabalho local e a validação externa permanece na INT-02. A main conferida mantém a F7 desligada e propostas/sacola simulada. Login, senha e texto do agente não autorizam escrita. Envio de pedido e pagamento continuam proibidos neste incremento.

Código integrado não comprova configuração operacional, deploy nem conversa completa no Telegram. Esta revisão é somente documental e preserva as evidências históricas.
